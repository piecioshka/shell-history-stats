Command line tool

shell-history-stats

Your shell has been keeping notes for years. This reads them back and tells you which commands, subcommands, flags and aliases you actually use - and which ones you never touch. 

npx shell-history-stats

See a sample report Source on GitHub

Runs entirely on your machine. No network access, no telemetry, and anything that looks like a secret is masked before it reaches the report.

What a run looks like

A single run over the sample history. Watch the recording.

What it tells you

  • The commands behind your muscle memory

    Ranked by how often you run them, with the share of runs that carried no flags at all.

  • The flags you actually use

    Per command, so you can see the three options you reach for and the dozens you have never typed.

  • Whether your aliases earn their keep

    Aliases are expanded, so gc counts towards git commit while still being ranked as a shorthand, with the characters it saved.

  • When you work

    By hour, weekday and month, with an honest count of the entries that carried no timestamp.

  • Where the rough edges are

    Likely typos, commands long enough to deserve an alias, and the directories you keep coming back to.

  • Reports you can keep

    Terminal tables by default, or Markdown, JSON and a self-contained HTML page.

Reads your shells on their own terms

Shell Format Timestamps
fish YAML-like, with paths per entry Always
zsh : <started>:<elapsed>;<command> With EXTENDED_HISTORY
bash One command per line Only with HISTTIMEFORMAT

Sections that need a timestamp say how many entries they had to skip, so a bash-heavy machine never quietly reports a partial picture.

Try it

# every history file found on this machine
npx shell-history-stats

# one shell, longer rankings
npx shell-history-stats --shell fish --top 30

# an HTML report for the last 90 days
npx shell-history-stats --format html --out report.html --since 90d
